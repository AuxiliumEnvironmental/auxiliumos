# AuxiliumOS Founder Homework Workbook

## How to use this workbook

This workbook is for decisions AI cannot safely invent. Fill it out over time. Do not try to answer everything in one sitting. Each section exists because the answer affects architecture, permissions, pricing, workflows, legal boundaries, security, or client expectations.

Use status labels:

- OPEN: unanswered.
- DRAFT: preliminary answer.
- REVIEW: needs legal/accounting/security/technical review.
- APPROVED: decision locked for build.
- VERSIONED: decision is in the Rules/Admin model and has a version.

When an answer is unknown, write “UNKNOWN - DO NOT BUILD YET” or “PLACEHOLDER - NEED REVIEW.” Do not let AI invent the answer.
