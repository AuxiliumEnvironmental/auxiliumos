# V1 Scope

## Goal
Build the foundation vertical slice: Account -> User Role -> Facility -> Incident Request -> Admin Queue -> Document Upload -> Document Release -> Client View -> Audit Event.

## Included
- Account and user membership basics
- Facility record basics
- Incident/request submission
- Admin queue
- Document metadata and release workflow
- Basic audit events
- Positive and negative access tests

## Not Included
- Full ROM engine
- Full sampling engine
- Full QBR automation
- Full vendor scorecards
- Full accounting integration
- Production client data
