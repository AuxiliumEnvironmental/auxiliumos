# Dedicated Lovable host overlay

These two host-owned components mirror the dedicated project, not a second editor.
Copy src/ paths to the matching host paths only after BASE.json matches the target.
They consume the maintained workspace text-scale hook and keep the fallback action
at least 44 by 44 CSS pixels. No offline caching logic, authentication, data scope,
OS adapter, publishing or DNS settings are changed by this overlay.
